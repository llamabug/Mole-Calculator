# Mole Calculator
A calculator to calculate moles in chemistry. Features actual moles!


<h3>Features</h3>
<ul>
  <li>A calculator for moles, mass, and molar mass</li>
  <li>A periodic table</li>
  <li>A tutorial page to help you manually calculate moles</li>
  <li>A page with info on stochiometry</li>
  <li>A page explaining what moles actually are</li>
</ul>

<h3>Process</h3>
I started with the actual calculator and web design, and then created the other 4 pages. The hardest part was setting up the different modes, but it was fun to learn new skills (like the <i>active</i> class in JS).
